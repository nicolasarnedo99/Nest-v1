- 2026-09-12: Funding and Apple Wallet notification intake can ship independently of the failed classifier when Nico reprioritizes them. Preserve the execution gate while completing receive-funds and durable intake flows; do not use classification as a blocker for unrelated authorized work.
- 2026-09-12: YouTube Premium is a direct Alphabet-owned service and Tesla service is a direct Tesla match. Rejecting speculative sector links must not reject owned services or treat Spanish servicio as a command. Verify revised prompts on held-out direct-service paraphrases and unrelated repair/video merchants.
- 2026-09-11: The implementation plan supersedes older chain, ownership, login, and native-app proposals below. Arc testnet AchRWA synthetic tokens are explicitly selected; QVAC and NVIDIA are mandatory. Treat the remote handoff as history.
- 2026-09-11: Verify the user's intended chain before optimizing execution. Arc is preferred; Hedera is acceptable only with a verified live stock venue. Do not silently substitute mock stocks or Solana.
- 2026-09-11: Card-event access and native presentation are separate dependencies. Resolve stock availability, wallet control, execution, and payment input before building the app.
- 2026-09-11: Nico explicitly deferred Privy secret rotation until after submission. Do not reintroduce it as an implementation gate; keep credentials private.
- 2026-09-12: A fresh preparation-only instruction overrides saved implementation and chain approvals. Preserve prior evidence, but put current gates above historical resume instructions before continuing.
- 2026-09-12: Test buy and redemption signatures separately. viem decodes RLP zero value as undefined; normalize only numeric zero before comparison, preserve every other immutable-field check, and recover with the exact saved bytes.

- 2026-09-12: When Nico reports that a device option cannot be found, do not repeat the same navigation instruction after screenshots. Acknowledge the reported blocker, distinguish it from proven platform limitations, and move to the agreed fallback or a different diagnostic.

- 2026-09-12: Apply Nico’s latest device findings and authorization to the checkpoint immediately. Transaction is found and implementation is approved; classification is deferred. Do not carry resolved navigation blockers forward, restart classifier work, or ask for blanket implementation approval. Distinguish a configured diagnostic from saved automation and observed real tap data.

- 2026-11-13: Before proposing real money to learn a protocol, check whether its contract source is public and can be deployed on a testnet. Nico's question ("it's open source, why can't we deploy it on Sepolia") was the better plan, and the verified source turned out to be readable on Sourcify.
- 2026-11-13: Do not state that a repository is public from a search result. I said USD₮0's GitHub repos were public; they returned 404. Check the repository itself, and say what was and was not verified.
- 2026-11-13: Read the engine before promising an adapter swap. The September engine assumed the wallet signs a transaction; a signed authorisation relayed by another key needed the engine rewritten, not a new adapter.
- 2026-11-13: Edit files with exact replacements that assert they matched, or rewrite the file. A multi-step find-and-replace script broke a test file and half-applied nothing to another.
- 2026-11-17: Commit commands handed to Nico must use single quotes around the message. In zsh, `!:` inside double quotes is history expansion, so `-m "feat(turtle)!: ..."` aborted the whole paste with "illegal modifier" and nothing was committed.
- 2026-11-18: Pin native-runtime dependencies exactly and check the SDK's supported range before installing. `react-native-bare-kit ^0.17.1` let in a release that no longer ships BareKit.framework; the app built, installed and only failed on the device. QVAC's own table stopped at 0.16.0 and its prebuild had warned "not in the built-in table".
- 2026-11-18: USD₮0 is deployed on about 17 chains. WDK's x402 docs listing only Plasma and Stable is a docs snapshot, likely outdated, not the limit of where USD₮0 or WDK's x402 support works. Don't repeat "x402 with USD₮0 means Plasma or Stable"; check USD₮0's current deployment list, and check EIP-3009 support per chain.
